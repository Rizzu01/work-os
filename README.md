# Work OS

A connected work-management platform inspired by modern tools such as monday.com and ClickUp.

## Product direction

Workspace → Teams → Projects → Boards → Groups → Tasks → Subtasks → Views → Reports

Core principle: create data once and reuse it everywhere. Tasks are the source of truth for List, Board, Calendar, Timeline, Gantt, Workload, Dashboard and Reporting views.

## Phase 1

- Workspace foundation
- Teams and members
- Projects
- Boards and groups
- Tasks and subtasks
- Task details, comments, files and activity
- My Work
- List and Kanban views
- Search and filters
- Notifications
- Reporting foundation

## Development rule

Build real connected functionality. Avoid mock data that pretends to be persisted. Keep the architecture modular so future views operate on the same underlying task model.
